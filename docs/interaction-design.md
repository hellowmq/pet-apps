# 交互优化契约

本次优化面向 Electron 桌宠与浏览器展示页。采用「交互大师」经验中的状态连续性、局部反馈、控制与表现分离、取消恢复；不引入展示型粒子、音效或分镜。

## 保留

- 团子模型、圆头耄耋素材、序列帧、动作、时长、运动路径及场景参数。
- 桌宠透明、无常驻工具栏；左键摸头、按住拖动、右键辅助操作、空白穿透。
- 现有浏览器调试页和展示页的暖色视觉、双语与嵌入模式。

## 状态与反馈

| 场景 | 用户感知 | 实现约束 |
| --- | --- | --- |
| 点按宠物 | 按下时可抓取，原位置释放才摸头 | 按下不触发动作；滑动超过阈值后不再算点击 |
| 拖动桌宠 | 鼠标与窗口保持连续关系 | 使用屏幕坐标；指针捕获；释放后保存位置 |
| 取消、失焦、切换 | 手势及时结束，不补发摸头 | 释放捕获和拖动状态；取消后恢复空白穿透 |
| 右键和托盘 | 互动、选择、窗口控制层级清楚 | 原生单选选中态；显示/隐藏根据窗口真实状态更新；退出单独分组 |
| 切换宠物 | 选择有局部反馈，当前宠物不重建 | 同一选项点击保持现有动作；不以重启动画充当反馈 |
| 展示页操作 | 控件立即按压反馈，说明本次请求 | 耄耋忙碌时可能忽略请求，不宣称动作已经成功 |
| 展示页点按 | 点击与按钮走同一入口 | 滚动、取消、拖出及右键不触发摸头 |
| 减少动态效果 | 控件状态仍然清楚 | 移除界面过渡；沿用静态预览与主动开启互动 |

界面过渡采用短促的 transform / opacity / 颜色变化；目标变化时从当前状态继续。切换指示保持同一对象，正文立即可读，状态区域保持尺寸，快速重复操作不叠加消息队列。

## 验收

1. 自动测试点击/拖动阈值、不同指针、取消、失焦、拖出释放和销毁后监听清理。
2. 全仓库测试与四个应用构建通过。
3. Electron 实际启动，验证窗口拖动、穿透状态、菜单选中与显示/隐藏、切换和动作入口。
4. 浏览器验证桌面/窄屏、中英、嵌入、减少动态效果、键盘、快速重复操作与 context loss。
5. Git diff 证明两只宠物实现与素材未改动。自动化渲染/IPC 验证与真人跨应用使用体验分开报告。

本地改动不代表线上或 Release 已更新；此次没有提交、推送或发布授权。


## 个人主页组件：把这只带走

书签入口仅属于 `?embed=maodie` 网页组件。桌面宿主保留原交互；角色素材、耄耋动作和宠物业务逻辑不变。网页里轻点宠物仍然发送互动请求，原生链接拖拽开始后取消点击手势，拖拽结束只提示下一步，不声称已经保存书签。键盘激活宠物入口会展开说明，手动创建方式给出完整 JavaScript 书签地址。

新版书签自包含渲染器和原有 48 帧 PNG，不创建 iframe，不请求外部脚本或图片，保存在书签栏后可离线召唤。通过 Shadow DOM 隔离界面，复用现有 `createPetRuntime`、团子及耄耋动作代码；只为耄耋加载器增加可选的图片地址映射，不改变原图、帧顺序、帧率、动作时长或运动逻辑。每页最多四只，可互动、移动和关闭；空白指针穿透、窗口边界和减少动态效果继续保留，不读取宿主正文、表单或 Cookie。

这修复了 `frame-src`（例如 X 的白名单）阻断跨域 iframe，以及另一设备无法访问 GitHub Pages 素材的问题；仅更换 CDN 或增加握手重试不能修复这类策略限制。书签仍可能受宿主的内嵌图片策略、样式策略、浏览器内部页面限制或 WebGL 可用性影响。加载期限 10 秒；图片被 CSP 拒绝或图形启动失败时显示明确失败及重试入口，不无限等待。保留 `companion.html` 以兼容旧书签；既有 iframe 书签不会自动升级，需要重新保存新版。

完整书签限制在 1,900,000 字符以内，为 Chromium 的 2 MiB URL 上限保留余量。通过独立 Windows、Linux CI 中的全新 Chromium 验证真实书签存储往返、严格 CSP 的 iframe 负对照、自包含书签在断网下的显示及操作、图片禁用时的失败收敛、减少动态效果、多实例和关闭清理。实际目标站点访问与策略夹具分开记录；上游拒绝访问不得记为目标站点通过。

验收：主页组件实际拖拽传出完整书签；点击与拖动不串扰；其他域名页面中的召唤、独立多实例、动作请求、移动、关闭和页面输入正常；中英文、窄屏、键盘、减少动态效果及加载失败有可用路径。生产构建中的序列化函数须实际运行验证，不能只检查源码。

素材就绪属于真实状态。耄耋帧加载限制为最多四个并发请求，每个失败帧最多重试两次；网页预览与书签实例等全部帧就绪后才开始播放。失败时保留稳定静态预览并提供重试，卸载忽略晚到的加载结果。该修复只涉及加载与启动时机，不修改原图片、帧顺序、帧率或动作逻辑。

抓起的反馈以宠物本体为边界。网页组件通过 `setDragImage` 使用当前姿态的透明裁切图，排除舞台、地面、粒子和说明文字；捕获时不推进宠物动画，并恢复原渲染状态。静态预览沿用已有透明 PNG。拖拽结束、取消或页面卸载时移除临时画布，完整书签载荷保持不变。
